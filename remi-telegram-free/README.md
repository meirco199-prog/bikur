הפתרון המומלץ: בוט טלגרם אישי שרץ על הענן החינמי של Cloudflare.

**למה זה עונה בדיוק על הצורך:**
- 🔔 **התזכורת מגיעה כהתראת טלגרם אמיתית** — מצלצלת וקופצת גם כשהטלגרם סגור, גם כשאתה באפליקציה אחרת. ככה טלגרם עובד מהיסוד.
- 🆓 **חינם לצמיתות** — התוכנית החינמית הרשמית של Cloudflare (לא תקופת ניסיון), בלי כרטיס אשראי.
- 💻 **שום מחשב לא צריך לרוץ אצלך** — הבוט חי בענן 24/7.
- 📅 **היומן שלך נשאר נקי** — הכול מנוהל בתוך הצ'אט עם הבוט.
- 🔒 **פרטי** — רק אתה יכול לדבר איתו (המשתמש הראשון ששולח /start הופך לבעלים).

## התקנה חד-פעמית (~15 דקות, בלי ידע טכני)

### שלב 1: יצירת הבוט בטלגרם (2 דקות)

1. פתח בטלגרם את **@BotFather** (חפש אותו בחיפוש)
2. שלח לו `/newbot`
3. תן שם: `רמי` ושם משתמש שמסתיים ב-bot, למשל: `meir_remi_bot`
4. **העתק את הטוקן** שתקבל (נראה כמו `123456:ABC-DEF...`) — נצטרך אותו בשלב 3

### שלב 2: חשבון Cloudflare (3 דקות)

1. היכנס ל-[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)
2. הירשם עם אימייל וסיסמה (לא צריך כרטיס אשראי)

### שלב 3: יצירת הבוט בענן (10 דקות)

1. בתפריט הימני: **Workers & Pages** → **Create** → **Create Worker**
2. תן שם (למשל `remi`) → **Deploy**
3. לחץ **Edit code**, מחק את כל הקוד שמופיע, והדבק במקומו את **כל** התוכן של הקובץ [`worker.js`](worker.js) → **Deploy**
4. חזור למסך ה-Worker → **Settings**:
   - **Variables and Secrets** → **Add**:
     - שם: `BOT_TOKEN`, סוג: **Secret**, ערך: הטוקן מ-BotFather
     - שם: `SECRET`, סוג: Secret, ערך: מחרוזת שאתה ממציא (למשל `remi-meir-2026`)
5. יצירת אחסון: בתפריט הראשי **Storage & Databases** → **KV** → **Create namespace** → שם: `remi-data`
6. חזרה ל-Worker → **Settings** → **Bindings** → **Add** → **KV namespace**:
   - Variable name: `DATA` (בדיוק ככה, באותיות גדולות)
   - בחר את `remi-data` → **Save**
7. הפעלת השעון: **Settings** → **Trigger Events** (או Triggers) → **Add** → **Cron Trigger** → הדבק: `* * * * *` (כל דקה) → **Save**

### שלב 4: חיבור (דקה)

1. פתח בדפדפן: `https://remi.<החשבון-שלך>.workers.dev/setup?secret=<ה-SECRET-שהמצאת>`
   (את הכתובת המדויקת של ה-Worker רואים במסך שלו תחת "Visit")
   אמור להופיע: `"ok":true`
2. פתח בטלגרם את הבוט שלך (לפי שם המשתמש שנתת) ושלח: `/start`

**זהו!** 🎉 שלח לו "תזכיר לי בעוד 2 דקות לבדוק שאתה עובד" — וסגור את טלגרם. ההתראה תגיע.

## חיבור יומן גוגל (אופציונלי, 3 דקות, בלי OAuth)

הבוט קורא את היומן דרך "הכתובת הסודית" של גוגל — קריאה בלבד, בלי הרשאות מסובכות:

1. פתח [calendar.google.com](https://calendar.google.com) **במחשב** (האפשרות לא קיימת בטלפון)
2. הגדרות ⚙️ → בצד שמאל בחר את היומן שלך → **שילוב היומן** (Integrate calendar)
3. העתק את **"כתובת סודית בפורמט iCal"** (Secret address in iCal format)
4. ב-Cloudflare: Worker → Settings → Variables and Secrets → **Add**:
   - Name: `CALENDAR_ICS`, סוג: **Secret**, ערך: הכתובת שהעתקת

מעכשיו "מה יש לי היום" והסיכום של הבוקר יציגו גם את הפגישות מהיומן (מסומנות 📆).

> הכתובת הזו נותנת קריאה של היומן לכל מי שמחזיק בה — לכן היא נשמרת כ-Secret. אם דלפה, אפשר לאפס אותה באותו מסך בגוגל.

## קביעת פגישות ביומן גוגל האמיתי (אופציונלי, 5 דקות)

כדי ש"קבע פגישה עם דני מחר ב-14:00" ייכנס ליומן גוגל עצמו — מקימים גשר קטן ב-Google Apps Script (חינם). ההוראות המלאות בתוך הקובץ [`calendar-bridge.gs`](calendar-bridge.gs): מדביקים אותו ב-script.google.com, מפרסמים כ-Web app, ומוסיפים את הכתובת כ-Secret בשם `CALENDAR_WEBHOOK`.

## הודעות קוליות (אופציונלי, דקה אחת)

תמלול עברית בחינם עם Workers AI (כלול בתוכנית החינמית):

1. Worker → Settings → **Bindings** → **Add** → בחר **Workers AI**
2. Variable name: `AI` → **Deploy**

מעכשיו אפשר להקליט לבוט הודעה קולית ("תזכיר לי מחר בתשע תור לרופא") והוא יתמלל ויבצע.

## טיפים

- **סיכום בוקר בשעה אחרת:** הוסף משתנה `BRIEF_HOUR` עם השעה הרצויה (למשל `7`), או `off` לביטול.
- הבוט מקשיב רק לך. אם מישהו אחר יכתוב לו — הוא יסרב בנימוס.
- כל הנתונים נשמרים בחשבון ה-Cloudflare **שלך** — לא אצל אף אחד אחר.
