# מרחב רגוע — אפליקציה לניהול ליווי רגשי לילדים 🫧

אפליקציית Web מלאה בעברית (RTL) לניהול טיפולים וליווי רגשי לילדים.
מאפשרת למטפל/הורה להוסיף ילדים, ולכל ילד לנהל תיקייה אישית עם מסמכים,
מצגות, תמונות, הערות טיפוליות, מזכורות, תרגולים רגשיים ולוח ציור.

נבנתה ב-**React + TypeScript + Vite + Tailwind CSS**, עם אחסון מקומי
ב-**IndexedDB** (עם נפילה חכמה ל-LocalStorage). כל הנתונים נשמרים בדפדפן —
ללא צורך בשרת בשלב זה.

---

## ✨ יכולות עיקריות

- **ניהול ילדים** — הוספה, עריכה ומחיקה. פרטים: שם מלא, גיל, כיתה, הערות
  כלליות, איש קשר. רשימת ילדים בכרטיסיות + פרופיל אישי.
- **תיקייה אישית** — העלאת מסמכים, מצגות ותמונות, צפייה לפי קטגוריות,
  הורדה ומחיקה, וכתיבת הערות טיפוליות.
- **מזכורות ומשימות** — תאריך, שעה, תיאור וסטטוס (פתוח/בוצע). מזכורות
  קרובות מוצגות בדף הילד ובדשבורד.
- **תרגול רגשי** — יצירת תרגול לפי סוג: ציור, כתיבה חופשית, שאלון רגשי,
  משימת בית, תרגול נשימות, הכרת רגשות. שמירת היסטוריית תרגולים.
- **לוח ציור** — Canvas עם תמיכה בעכבר ובמגע (אצבע). כלים: בחירת צבע, מחק,
  עובי קו, ניקוי הלוח ושמירה. הציור נשמר בתיקיית הילד.
- **תרגול שוטף** — תרגול קבוע (יומי/שבועי/חד פעמי) עם שם, הנחיה, תאריך יעד,
  סטטוס ביצוע והערת מטפל.
- **דשבורד ראשי** — מספר ילדים, מזכורות קרובות, תרגולים פתוחים, ילדים עם
  פעילות אחרונה, וכפתור מהיר להוספת ילד.
- **עיצוב רגוע** — ממשק נקי, צבעים רכים, תמיכה מלאה ב-RTL, אייקונים
  ידידותיים, והתאמה למחשב/טאבלט/מובייל.
- **אבטחה ופרטיות** — מסך התחברות, בידוד מלא בין תיקיות ילדים, ואזהרה לפני
  כל מחיקת מידע.

## 🚀 הרצת הפרויקט

דרישות מוקדמות: **Node.js 18+**.

```bash
cd therapy-app

# התקנת תלויות
npm install

# הרצה במצב פיתוח (נפתח אוטומטית בדפדפן בכתובת http://localhost:5173)
npm run dev

# בנייה לפרודקשן
npm run build

# תצוגה מקדימה של גרסת הפרודקשן
npm run preview
```

## 🗄 אחסון נתונים

כל הנתונים (כולל קבצים מקודדים ב-base64) נשמרים מקומית בדפדפן דרך
**IndexedDB**, עם נפילה אוטומטית ל-LocalStorage אם IndexedDB אינו זמין.
שכבת האחסון (`src/lib/storage.ts`) מבודדת לחלוטין — היא הנקודה היחידה שבה
מתבצעות קריאות קריאה/כתיבה.

> 💡 **הערה:** הנתונים נשמרים בדפדפן ובמחשב הספציפי. ניקוי נתוני הדפדפן ימחק
> אותם. גודל קובץ מקסימלי להעלאה: 8 מ״ב (ניתן לשינוי ב-`ChildFiles.tsx`).

## 🔌 חיבור עתידי לשרת, משתמשים והרשאות

הקוד תוכנן כך שיהיה קל להרחיב אותו לשרת אמיתי:

1. **אחסון** — להחליף את המימוש ב-`src/lib/storage.ts` בקריאות REST/API
   (או Firebase/Supabase). שאר האפליקציה לא משתנה כלל.
2. **אימות** — `src/context/AuthContext.tsx` מרכז את כל לוגיקת ההתחברות.
   להחליף ב-JWT / OAuth ולהוסיף ניהול session אמיתי.
3. **הרשאות** — מודל הנתונים כבר מקשר כל ישות ל-`childId`, כך שקל להוסיף
   שכבת `userId` / `therapistId` והרשאות גישה ברמת השרת.
4. **מודולריות** — כל אזור פונקציונלי הוא קומפוננטה נפרדת המקבלת `childId`,
   מה שמקל על הרחבה והוספת תכונות.
