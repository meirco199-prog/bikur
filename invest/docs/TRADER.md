## התקנה (Actions → Trading assistant → install)
- **סודות קיימים:** `SERVER_HOST`, `SERVER_ROOT_PASSWORD`, `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY`, `CRON_SECRET`.
- **לכל חשבון** (`CO` = חברה, `PR` = פרטי):
  - `IBKR_FLEX_TOKEN_CO`, `IBKR_FLEX_ACTIVITY_CO`, `IBKR_FLEX_TRADES_CO`.
  - `IBKR_FLEX_TOKEN_PR`, `IBKR_FLEX_ACTIVITY_PR`, `IBKR_FLEX_TRADES_PR`.
- **בלי מפתחות Flex** המערכת כבר עובדת למניות במעקב ולבדיקה לפני קנייה, אבל לא רואה פוזיציות.
- **הסודות נשמרים רק על השרת** (‎`/etc/bikur-trader/trader.env`). הלוגים של Actions ציבוריים, ולכן כל פלט ממוסך: טוקנים, כתובות ומספרי חשבון.

### יצירת דוחות Flex ב-IBKR (מאיר, פעם אחת לכל חשבון)
1. **הפורטל של IBKR** (‎`https://www.interactivebrokers.com/portal`): Performance & Reports → Flex Queries.
2. **Activity Flex Query** (לחיצה על +):
   - **שם:** `bikur-activity`.
   - **סעיפים:** Open Positions (Summary), Net Asset Value (NAV) in Base, Conversion Rates.
   - **הגדרות:** Format: XML. Period: Last Business Day.
   - שמור, ורשום את ה-Query ID.
3. **Trade Confirmation Flex Query:**
   - **שם:** `bikur-trades`.
   - **סעיפים:** Trade Confirmations — Executions.
   - **הגדרות:** Format: XML. Period: Today.
   - שמור, ורשום את ה-Query ID.
4. **Flex Web Service Configuration:** Enable, ואז Generate New Token. כדאי לבחור תוקף ארוך. הטוקן הוא **לקריאה בלבד** ואינו מאפשר מסחר.
5. **ב-GitHub:** Settings → Secrets and variables → Actions → New repository secret.
   - **החשבון הפרטי:** `IBKR_FLEX_TOKEN_PR`, `IBKR_FLEX_ACTIVITY_PR`, `IBKR_FLEX_TRADES_PR`.
   - **חשבון החברה:** אותם שמות עם `_CO`.
6. **בסוף:** Actions → Trading assistant → install.

## חלופה בלי Flex — העברה שעתית (החלטת מאיר, 26/11/2026: "חלופה")
מאיר בחר לא ליצור מפתחות Flex. במקומם:
1. **משימה מתוזמנת** (סשן חדש בכל שעה עגולה, בימי מסחר 04:07–18:07 ניו יורק) קוראת — **קריאה בלבד** — את שני החשבונות דרך החיבורים של IBKR:
   פוזיציות, סיכום חשבון וביצועים של היום. הפלט נשמר כמו שהוא לקבצים זמניים.
2. `node invest-api/scripts/trader-push.mjs --pub <מפתח ציבורי> --dir <תיקייה>` בונה תמונת מצב **בלי מספרי חשבון** (רק PR/CO), דוחס ומצפין
   (X25519 + AES-256-GCM, `engine/trader-push.js`). רק השרת מחזיק את המפתח הפרטי (`/etc/bikur-trader/push.key`, נוצר ב-install ולא יוצא מהשרת).
3. המשימה מפעילה את `trader.yml` עם `action=push` ו-`payload=<מוצפן>`. הקלט של workflow_dispatch גלוי בריפו הציבורי — לכן רק מוצפן.
   ה-workflow מעביר את הקובץ לשרת ב-SSH, והשירות מפענח, בודק מבנה (`validSnapshot`) ומשתמש בו.
- **פוזיציות:** הכמות והעלות מ-IBKR; "נפתחה היום" ושעת הכניסה משוחזרות מהביצועים של היום (`snapshotLive`).
- **עיכוב:** עד שעה. המחירים עדיין כל דקה. תמונת מצב בת יותר משעתיים וחצי — התראות על פוזיציות מושהות (אולי כבר נמכרו), והמסך מציין את זה.
- **שער הדולר** (חשבון בשקלים): שווי הפוזיציות בשקלים חלקי שוויין בדולרים; בלי פוזיציות — השער האחרון שידוע לשרת.
- **מפתח ציבורי:** מודפס ב-install ובפעולה `pubkey`. לא סודי.
