# האוטומט — AUTOPILOT.md

ניהול אוטומטי של **חשבון התרגול** (paper). כללים קבועים בקוד (`invest-api/engine/autopilot.js`), בלי LLM.
המטרה: לצבור רקורד אמיתי של החלטות המערכת לאורך זמן לפני כל דיון בכסף אמיתי.

## מתי רץ
- פעם ביום, אחרי שהעיבוד הלילי הסתיים (`rank:{day}` נוצר): מה-cron של Cloudflare (`scheduled`) או מה-workflow
  `tick-invest.yml` (`/auto/run?secret=CRON_SECRET`). ריצה כפולה באותו יום נחסמת (`auto:journal`).
- ידנית מהאפליקציה: "התיק שלי" → "הרץ עכשיו" (טוקן). `force=1` מותר רק עם טוקן.
- כיבוי/הפעלה: `POST /settings {autopilot:false|true}`; פרופיל סיכון: `{riskProfile}`.

## הכללים (`AUTO_RULES` + `PROFILES[profile]`)
| כלל | ערך (מאוזן) |
|---|---|
| מכירה מלאה | סיגנל `SELL`, או הפסד ≥ 12% מהקנייה (8% בשוק דובי) |
| מכירה חלקית | סיגנל `REDUCE` → חצי מהכמות |
| קנייה | רק `STRONG BUY` / `BUY`, ציון ≥ `minScore` (60), לפי סדר: קנייה חזקה קודם, אחר כך ציון |
| יעד לנייר | `maxPosition` (10%) × 1.0 לקנייה חזקה / 0.7 לקנייה; ETF עד `maxEtfPosition` (35%) |
| שלבים | כל קנייה = שליש מהיעד; לא ממשיכים אם כבר ב-90% מהיעד |
| מכסות | עד 3 קניות בריצה; עד `maxStocks`+2 פוזיציות; ענף ≤ `maxSector` (30%) |
| חסימות | דוח בתוך 5 ימים; `vol1y` > `maxVol`; פקודה < 1,500 ₪; רזרבת מזומן `sleeves.cash` (5%) |
| משטר | `Bear Trend`: אין קניות. `Risk Off`: רק קנייה חזקה, חצי גודל |
| ביצוע | שער חי (`getQuote`) ואם אין — סגירה אחרונה; סטייה > 25% מהסגירה → דילוג (תקלת נתונים) |
| ירושה | חשבון עם מזומן שלילי (קניות מלפני מודל המזומן) מאופס פעם אחת עם ארכוב, ונרשם ביומן |

## יומן
`auto:journal` (append-only, עד 400 רשומות): לכל ריצה — יום, טריגר, משטר, לפני/אחרי (סה"כ, מזומן, מספר פוזיציות),
פקודות (עם `reason` בעברית, מחיר ומקור), `skipped` (מי נדחה ולמה), `notes`. מוצג ב"היום" וב"התיק שלי".

## מה זה לא
- לא ביצוע בכסף אמיתי. שכבת ברוקר אמיתית (IBKR) היא שלב נפרד עם כללי בטיחות משלה (IMPLEMENTATION_PLAN שלב 3).
- לא תחזית. הרקורד שנצבר הוא forward test: החלטות שנרשמו בזמן אמת, לא backtest.
