# רמי בוואטסאפ — גרסה חינמית לגמרי 🆓

עוזר אישי בוואטסאפ בסגנון Remi, **בלי מנוי חודשי, בלי API בתשלום, בלי מספר טלפון נוסף**:

- ⏰ **תזכורות** — "תזכיר לי מחר ב-9 להתקשר לדני", "תזכיר לי בעוד 20 דקות...", "תזכיר לי כל יום ב-8..."
- 📋 **משימות** — "משימה: לשלם ארנונה", "משימות", "סיימתי 1"
- 📅 **יומן** — "קבע פגישה עם דני ביום רביעי ב-14:00", "מה יש לי היום/מחר/השבוע"
- 🌅 **סיכום בוקר** — כל יום ב-8:00 הודעה עם האירועים, התזכורות והמשימות של היום

## איך זה חינמי?

הבוט מתחבר לחשבון הוואטסאפ **שלך** דרך פרוטוקול WhatsApp Web — בדיוק כמו שמחברים וואטסאפ למחשב (סריקת QR חד-פעמית). הוא מקשיב רק לצ'אט **"הודעות לעצמי"** ועונה שם. כל ההבנה של העברית נעשית בקוד מקומי — בלי שליחת מידע לשום שירות חיצוני.

> ⚠️ **שקיפות מלאה:** החיבור נעשה עם ספריית קוד פתוח ([Baileys](https://github.com/WhiskeySockets/Baileys)) שמדמה WhatsApp Web. זה לא API רשמי של Meta, ותאורטית מנוגד לתנאי השימוש שלה. בפועל מיליוני אנשים משתמשים בזה לבוטים אישיים, והסיכון לחשבון פרטי בשימוש אישי (רק צ'אט עם עצמך) נמוך — אבל חשוב שתדע. אם אתה מעדיף את הדרך הרשמית של Meta (דורשת מספר ייעודי ושרת), ראה `../remi/README-whatsapp.md`.

## התקנה (5 דקות)

דרישה: [Node.js](https://nodejs.org) גרסה 18 ומעלה, על מחשב (או טלפון אנדרואיד ישן עם Termux).

```bash
cd remi-wa
npm install
npm start
```

בהפעלה הראשונה יופיע קוד QR בטרמינל:

1. פתח וואטסאפ בטלפון
2. הגדרות ← **מכשירים מקושרים** ← **קישור מכשיר**
3. סרוק את הקוד

זהו. עכשיו פתח בוואטסאפ את הצ'אט עם עצמך ("הודעות לעצמי" — חפש את השם שלך) וכתוב **עזרה**.

## הגדרות אופציונליות (משתני סביבה)

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `BRIEF_HOUR` | `8` | שעת סיכום הבוקר (`off` לביטול) |
| `ALLOWED_NUMBER` | — | מספר נוסף שמורשה לדבר עם הבוט (למשל `972501234567`), אם מריצים אותו על מספר שני |
| `TZ` | `Asia/Jerusalem` | אזור זמן |

למשל: `BRIEF_HOUR=7 npm start`

## כדי שהתזכורות יעבדו — הבוט צריך לרוץ

הבוט שולח תזכורות רק כשהוא פועל. אפשרויות בחינם:

- **מחשב בית שדולק** — פשוט להשאיר את הטרמינל פתוח (או `nohup npm start &`)
- **טלפון אנדרואיד ישן** — להתקין [Termux](https://termux.dev), בתוכו `pkg install nodejs git`, ולהריץ. מכשיר מחובר לחשמל = שרת חינמי מצוין
- **Oracle Cloud Free Tier** — שרת ענן חינמי לצמיתות (דורש הרשמה עם כרטיס אשראי לאימות בלבד)

אחרי ניתוק (הפסקת חשמל וכו') פשוט מריצים שוב `npm start` — החיבור נשמר בתיקיית `auth/`, אין צורך לסרוק QR שוב.
